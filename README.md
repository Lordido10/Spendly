# Spendly

Spendly is a personal expense and budget tracker designed to help users manage and understand their spending.

## Features

- Track balance
- Add income
- Add expenses
- Categorize expenses
- Set daily spending limits
- View spending insights
- Create saving goals
- Track monthly spending summary

## Tech Stack

- HTML
- CSS
- JavaScript

## Status

Spendly is currently in development.

This is the initial MVP version. More features and UI improvements will be added in future updates.
